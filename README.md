# Dani Hill website

Static site for Dani Hill (Puncak Dani), Genting Highlands.

- `index.html` — weddings (home)
- `residences.html` — hosted residences
- `gallery.html` — gallery (Weddings, The Mansion, Villa Dani, Special Events)
- `styles.css`, `img/`

No build step. Deploy as a static site (for example on Vercel) with the repo root as the output directory.
The home page weather widget reads live data from Open-Meteo in the browser.
